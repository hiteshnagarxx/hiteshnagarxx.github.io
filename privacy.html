Privacy Policy - AIF Uploader

Last updated: 14 November 2026

What the app does

AIF Uploader is an internal tool run by the channel owner on his own computer. It uploads the owner's own videos to the owner's own YouTube channels and manages their metadata (titles, descriptions, tags, captions, playlists, thumbnails) using the YouTube Data API.

Data accessed

With the owner's consent through Google sign-in, the app uses the YouTube scopes youtube.upload and youtube.force-ssl to read basic channel information (channel id and title) and to upload and edit videos on those channels. It does not access any other Google data.

Storage

OAuth tokens are stored only on the owner's own computer. No YouTube data is sold, shared with third parties, or used for advertising. No data from other users is collected.

Google API Services User Data Policy

AIF Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Tokens are deleted from the owner's computer on request.
